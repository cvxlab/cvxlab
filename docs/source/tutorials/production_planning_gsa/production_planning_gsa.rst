.. _tutorial-gsa:

Production planning: global sensitivity analysis
=================================================

This tutorial extends the deterministic production planning model
introduced in :ref:`tutorial-production-planning` , which maximizes
total profit by optimizing the production levels of two products
subject to energy and material availability constraints.

We now consider the availability of these two resources as uncertain inputs:

- **Energy availability** (:math:`E`), expressed in kWh.
- **Material availability** (:math:`M`), expressed in kg.

In the :download:`zip directory <production_planning_gsa.zip>`, the materials related 
to this tutorial are available, including:

- ``notebook.ipynb`` file: Jupyter Notebook with the complete workflow of the 
  tutorial, including code and comments.
- ``concept.xlsx`` file: Excel workbook with the conceptual model definition, 
  resolving the model with the built-in solver. Useful to understand how the 
  model works and the expected results.
- ``model`` directory: model directory generated by CVXlab, containing: model settings 
  (available in both xlsx and YAML formats), sets file ``sets.xlsx``, SQLite file 
  ``database.db``

.. admonition:: Problem statement

   Let us consider a production system capable of producing two types
   of goods: :math:`product_1` and :math:`product_2`, measured in
   :math:`units`. The system is characterized by the features listed below.

   - The production levels of the products are **independent**.

   - Production of each product generates constant **profit**, **energy**
     and **material** consumption per unit of output (i.e., no economies
     of scale or other nonlinearities are considered).

     .. math::

        \begin{array}{c|cc}
        & product_1 & product_2 \\
        \hline
        c [€/u] & 1.0 & 2.2 \\
        e [kWh/u] & 1.7 & 3.5 \\
        m [kg/u] & 0.5 & 1.2
        \end{array}

   The objective of the model is to determine the **maximum-profit
   production plan**, considering different scenarios for energy
   (:math:`E`) and material (:math:`M`) availability.

   In this example, the availability of these resources
   is **uncertain**, varying within the following ranges:

   .. math::

      \begin{array}{c|cc}
      & low & high \\
      \hline
      E [kWh] & [100, 200] & [250, 350] \\
      M [kg] & [50, 70] & [80, 100]
      \end{array}




Conceptual model definition
---------------------------

Related user guide step: :ref:`conceptual-model-definition`.

The conceptual model follows the same structure as the deterministic
:ref:`tutorial-production-planning`, with a few modifications
introduced to support GSA.

.. rubric:: Defining Sets

The model sets remain unchanged from the deterministic
:ref:`tutorial-production-planning`.

.. rubric:: Defining Data Tables and related Variables

For the GSA, two additional elements must be identified:

- **Uncertain inputs:** Model parameters whose values are subject to
  uncertainty and whose influence on model outputs is to be assessed.
  In this example, energy availability (:math:`E`) and material
  availability (:math:`M`).
- **Uncertainty measures:** Model outputs of interest for which
  sensitivity indices are computed to quantify the influence of
  uncertain inputs. In this example, total profit (:math:`P`).

To explicitly represent total profit, an additional scalar endogenous
variable :math:`P` is introduced, defined through the Data Table
``total_profit``.

All other Data Tables and Variables remain unchanged from the
deterministic tutorial.

.. rubric:: Defining Problem and related Expressions

Unlike the deterministic formulation, where total profit is expressed
directly in the objective function, the additional variable :math:`P`
is linked to the production decisions through the expression:

.. math::

   P = c \cdot x'

The optimization problem is therefore formulated as:

.. math::

   \begin{aligned}
   \max \quad & P \\
   \text{s.t.} \quad
   & P = c \cdot x' \\
   & e \cdot x' - E \leq 0 \\
   & m \cdot x' - M \leq 0 \\
   & x \geq 0
   \end{aligned}

This formulation is mathematically equivalent to the deterministic
problem, with total profit explicitly represented by a scalar endogenous
variable :math:`P`, enabling its use as the output of interest for the GSA.


Generation of model directory
-----------------------------

Related user guide step: :ref:`generation-of-model-directory-gsa`.

The model directory is generated as in the deterministic tutorial.
However, to enable the GSA functionalities, the parameter
``uncertainty=True`` must be specified when calling
``cvxlab.create_model_dir()``.

.. tabs::

   .. group-tab:: YAML

      .. code-block:: python

         import cvxlab

         cvxlab.create_model_dir(
             settings_file_type='yml',
             uncertainty=True,
         )

   .. group-tab:: XLSX

      .. code-block:: python

         import cvxlab

         cvxlab.create_model_dir(
             settings_file_type='xlsx',
             uncertainty=True,
         )

This generates the model setup templates with the additional fields
required to configure uncertain inputs and uncertainty measures.

Uncertainty settings
--------------------

Related user guide step: :ref:`uncertainty-settings`.

The objective of this analysis is **factor fixing**, i.e., identifying
uncertain inputs that have a negligible influence on total profit
(:math:`P`) and can potentially be fixed at representative values.

For this purpose, the **Morris method** is selected. Morris is a
screening method based on elementary effects, particularly suited
to identifying non-influential factors with a relatively limited
number of model evaluations.

The sampling and GSA settings are configured as follows:

.. code-block:: python

   model.uncertainty_settings(
       sampling_method="morris",
       gsa_method="morris",
       file_format="xlsx",
       sampling_kwargs={
           "N": 100,
           "num_levels": 4,
           "optimal_trajectories": 10,
           "seed": 123,
       },
   )

In this example:

- ``N=100`` generates 100 candidate Morris trajectories.
- ``num_levels=4`` defines the number of levels used to discretize
  each uncertain input range.
- ``optimal_trajectories=10`` selects 10 trajectories from the
  candidate set to improve their coverage of the input space.
- ``seed=123`` ensures reproducibility of the sampling procedure.

The Morris analysis computes two main sensitivity indices:

- :math:`\mu^*`: Mean absolute elementary effect, measuring the
  overall influence of each uncertain input on total profit.
- :math:`\sigma`: Standard deviation of elementary effects, indicating
  variations in input effects that may arise from nonlinearities
  and interactions.

Uncertain inputs associated with low :math:`\mu^*` values are
considered candidates for factor fixing.


Initialization and run of numerical problem(s)
----------------------------------------------

Related user guide step: :ref:`numerical-problem-init-run-gsa`.

The uncertainty analysis is executed through ``model.run_uncertainty()``,
which automatically handles the initialization of numerical problems,
generation of uncertainty samples, repeated model evaluations, and
computation of the Morris sensitivity indices.

.. code-block:: python

   model.run_uncertainty(
       n_parallel=4,
   )

In this example, ``n_parallel=4`` enables the concurrent execution
of up to four model evaluations on the local machine.

Once the analysis is completed, CVXlab exports the uncertainty samples,
the corresponding uncertainty measures, and the GSA results according
to the export options previously defined in the uncertainty settings.
By default, ``save_samples``, ``save_measures``, and ``save_gsa`` are
set to ``True``, and ``file_format`` is set to ``xlsx``.
